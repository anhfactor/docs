# Admin (chỉ Super Admin)

Menu Admin chỉ hiển thị với Super Admin (đội vận hành GreenNode) và quản trị viên khách hàng được cấp quyền. Người dùng thông thường có thể bỏ qua mục này.

| Tab                 | Nội dung                                                  |
| ------------------- | --------------------------------------------------------- |
| Quản lý thẻ         | Nhãn phân loại mô hình (POPULAR, INSURANCE, ID, BANKING…) |
| Mô hình AI          | Danh mục mô hình toàn hệ thống                            |
| Đồng bộ thuốc       | Đồng bộ danh mục thuốc quốc gia                           |
| Tenant              | Danh sách tenant và chính sách lưu trữ                    |
| Quản lý người dùng  | Toàn bộ người dùng hệ thống                               |
| Quản lý ứng dụng    | Danh mục connector/app                                    |
| Danh sách mô tả lỗi | Thông báo lỗi thân thiện cho từng mã lỗi                  |
