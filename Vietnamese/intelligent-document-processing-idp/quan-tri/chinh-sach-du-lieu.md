# Chính sách dữ liệu

Cấu hình lưu trữ:

•     Chọn Sử dụng storage do người dùng tự quản lý để lưu tài liệu vào object storage của doanh nghiệp.

•     Điền Access Key, Secret Key, Endpoint, Region, Bucket. Tuỳ chọn: _Sử dụng kiểu đường dẫn_, _Phân mảnh tệp_.

•     Bấm Gửi.

Thời hạn lưu trữ:

•     Mặc định hệ thống lưu dữ liệu 90 ngày và tệp 90 ngày.

•     Quá hạn, dữ liệu được che (redact) tự động: hồ sơ vẫn còn trong danh sách nhưng nội dung trống.

•     Muốn thay đổi thời hạn, liên hệ quản trị hệ thống.
