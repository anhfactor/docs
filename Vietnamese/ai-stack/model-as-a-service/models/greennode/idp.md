# GreenNode IDP

> Trang này được sinh tự động từ danh mục model của GreenNode MaaS. Chỉnh sửa tay sẽ bị ghi đè ở lần đồng bộ sau.

Model ID: `greennode/idp` · Loại: OCR

GreenNode IDP is an Intelligent Document Processing solution researched and developed by GreenNode. Unlike traditional OCR technologies that only convert images into plain text, GreenNode IDP integrates three core technologies—OCR, GenAI, and LLM—allowing the system not only to recognize but also to understand semantics, accurately extract data, validate information, and automatically classify documents.
