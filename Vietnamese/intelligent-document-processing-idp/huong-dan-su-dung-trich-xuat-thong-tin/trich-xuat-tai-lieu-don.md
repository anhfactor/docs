# Trích xuất tài liệu đơn

Để thực hiện trích xuất 1 loại tài liệu, bạn thực hiện theo các bước sau đây:&#x20;



**Bước 1:** chọn menu Extractor.

**Bước 2:** tại màn hình này, lần lượt cung cấp các thông tin sau:&#x20;

* Chọn OCR Single để trích xuất tài liệu đơn.&#x20;
* Chọn API KEY được cung cấp.&#x20;
* Chọn loại tài liệu bạn cần trích xuất (OCR)&#x20;
* Chọn loại file để tải mẫu, có 02 loại file được phép tải là Image hoặc PDF. &#x20;
* Với file Image (ảnh): Với đầu vào là hình ảnh, kích thước mỗi file ảnh không vượt quá 10MB, mỗi ảnh chỉ chứa 1 trang tài liệu. Nếu BCT có nhiều trang thì phải đảm bảo đúng thứ tự các trang tải lên. Số lượng ảnh cho phép tải lên có thể thay đổi (config) trong hệ thống phụ thuộc vào yêu cầu của người dùng. &#x20;
* Với file PDF: Chỉ cho phép upload 01 file PDF, kích thước file không vượt quá 50MB. &#x20;

&#x20;**Bước 3:** Sau khi tải xong mẫu (file), nhấn Submit để tiến hành trích xuất thông tin. Hệ thống sau khi xử lý sẽ trả kết quả phân loại tài liệu.

Đối với loại tài liệu có bảng, hệ thống sẽ hiển thị kết quả trích xuất bảng, trong đó các ô có độ tin cậy thấp sẽ được tô đỏ.
